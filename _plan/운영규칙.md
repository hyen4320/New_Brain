# 1. 지속성 장치 (계획보다 우선)

## 1-1. 주간 리듬 템플릿

| 요일 | 구간 | 내용 | 도구 |
| --- | --- | --- | --- |
| 토 (3h) | 0:00–0:20 | 복습큐에서 기한 지난 항목부터 | review-loop |
| | 0:20–2:40 | **메인 트랙** 새 학습: 노트 작성, 코드 작성, 도출 | 단계별 지정 도구 |
| | 2:40–3:00 | 기록: 노트의 '내가 틀렸던 것' 갱신, 주간 로그 작성 | — |
| 일 (3h) | 0:00–0:15 | 복습큐 | review-loop |
| | 0:15–2:00 | **수학 트랙** (1h45m) | math-proof-lab |
| | 2:00–2:40 | 메인 트랙 마무리: 통과 기준 시험, 또는 토요일 작업 이어서 | code-examiner / 지정 도구 |
| | 2:40–3:00 | 기록 + **다음 주 토요일 첫 15분에 할 일 한 줄** 적기 | — |

주간 배분은 메인 약 3h, 수학 약 1h45m, 복습 약 35m, 기록 약 40m입니다. Java 언어 트랙도 진행 중일 때는 **메인 트랙 자리**를 씁니다.

**통근 중 복습(선택, 의무 아님):** 복습큐 노트의 '결론' 한 줄과 '내가 틀렸던 것' 표만 읽습니다. 안 해도 계획에 영향이 없고, 주간 시간에도 산입하지 않습니다.

## 1-2. 최소 실행 단위 (MVU)

- **MVU = 45분: 복습 15분 + 진행 중 단계의 통과 기준 1개에 30분.**
- 컨디션이 나쁜 주에는 MVU를 1회만 해도 그 주를 **"유지"로 기록**합니다. 연속 기록은 끊기지 않습니다.
- MVU에서 메인과 수학 중 무엇을 할지는 **지난번에 건너뛴 쪽**으로 정합니다.

## 1-3. 밀렸을 때 규칙

1. **보충 금지.** 밀렸다고 다음 주를 6시간 넘게 쓰지 않습니다. 계획은 압축하지 않고 뒤로 밉니다.
2. **버퍼 주가 흡수합니다.** 5주차마다 오는 버퍼 주에는 밀린 단계를 이어서 합니다. 밀린 것이 없으면 복습큐 정리, 정체 항목 재공략, 노트 다듬기를 하고, **쉬는 것도 허용**합니다.
3. **버퍼로도 못 메우면**(한 블록에서 2주 넘게 밀림), 다음 블록의 단계 하나를 `_plan/백로그.md`로 옮깁니다. 삭제가 아니라 이동입니다. 다른 단계의 **선행인 단계는 옮길 수 없습니다**(의존 화살표 기준).
4. **3주 이상 공백 후 복귀하면 첫 주는 "재진입 주"입니다.** 새 학습 없이 복습큐를 처리하고, 마지막으로 통과한 단계의 통과 기준을 다시 시험합니다. 실패하면 그 단계부터 재개합니다.
5. **복습 과부하:** 기한 지난 복습 항목이 10개를 넘으면 그 주 토요일 메인 시간 중 최대 60분을 복습으로 돌립니다. 새 학습은 줄어도 괜찮습니다.
6. **정체 판정:** 한 단계가 예정 시간의 2배를 넘기면 단계를 둘로 쪼개거나, 복습큐 '정체 항목'에 기록하고 접근을 바꿉니다.
7. **진단에서 이미 숙련도 4 이상인 주제**는 해당 단계를 "통과 기준 시험만"(1세션)으로 줄입니다. 남는 시간은 새 내용이 아니라 **버퍼로 돌립니다**.
