## D1 — 리스트 앞에 넣기 vs 뒤에 넣기
```python
a = []
for i in range(n):
    a.append(i)        # (가) 뒤에 넣기

b = []
for i in range(n):
    b.insert(0, i)     # (나) 맨 앞에 넣기
```
n을 2만 → 4만 → 8만으로 2배씩 늘립니다.

(1) (가) 전체 시간은 n이 2배가 될 때 약 몇 배가 될까요?
(2) (나)는 약 몇 배가 될까요?
(3) 둘이 다르다면, **리스트가 메모리에 어떻게 놓여 있기 때문에** 그런지 설명하세요.

예측 (1):모름
예측 (2):모름
이유 (3):모름

## D2 — 리스트에서 찾기 vs 집합에서 찾기
```python
data_list = list(range(n))
data_set  = set(range(n))
# 없는 값 -1 을 1000번 찾기
for _ in range(1000):
    -1 in data_list    # (가)
for _ in range(1000):
    -1 in data_set     # (나)
```
(1) n이 2배가 되면 (가)는 약 몇 배?
(2) (나)는 약 몇 배?
(3) 왜 다른가요? `in`이 각각 내부에서 무엇을 하고 있다고 생각하나요?
